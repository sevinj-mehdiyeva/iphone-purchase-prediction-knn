# iPhone Purchase Prediction using KNN

This is a simple Machine Learning project using Python.

The goal of this project is to predict whether a customer will buy an iPhone based on their age.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Loaded and explored the dataset
- Checked for missing values
- Split the data into training and testing sets
- Built a KNN classification model
- Tested different K values (1, 3, 5)
- Evaluated the model using accuracy and confusion matrix

## Results
The best accuracy was **85%** using KNN with K=5.
